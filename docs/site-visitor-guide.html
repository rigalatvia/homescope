HomeScope GTA Site Visitor Guide

A practical guide for using HomeScope GTA to search listings, compare schools, save searches, request details, book showings, and use buyer and renter tools.

1. What You Can Do

HomeScope GTA helps visitors move from browsing to a more organized search.

  • Search GTA homes for sale and lease.
  • Open detailed listing pages with photos, MLS numbers, facts, descriptions, and tools.
  • Save homes and compare them later.
  • Save searches and turn on listing alerts.
  • Search schools and see nearby homes.
  • Use buyer and renter guides.
  • Estimate mortgage payments and land transfer tax.
  • Request a private showing.
  • Ask for more details about a listing.
  • Use the HomeScope assistant for help navigating the site.

2. Search Listings

Use /listings to browse available homes.

Common Filters

  • City or market
  • Sale or lease
  • Price
  • Bedrooms and bathrooms
  • Property type
  • Address or MLS number

Useful Workflow

  1. Apply filters.
  2. Open listing cards that look relevant.
  3. Save homes you want to compare.
  4. Save the search if you want alerts.

3. Listing Detail Pages

Each listing page can include:

  • property photos
  • price, address, city, and MLS number
  • property type, bedrooms, bathrooms, and square footage range when available
  • property description
  • mortgage payment calculator for sale listings
  • related buyer or renter guides
  • Save, Book a Private Showing, and Ask for Details buttons

4. Ask for Details

Use Ask for Details when you have a question about a listing but are not ready to book a showing.

You can ask about the property, pricing, MLS number, neighbourhood, schools, documents, next steps, or any specific question.

You will be asked for your email so HomeScope GTA can reply. After submitting, you will see a confirmation message on the listing page.

5. Book a Private Showing

Use Book a Private Showing when you want to request a visit to a property.

  • Enter your contact details.
  • Choose a preferred showing date and time.
  • Add notes if there is anything specific HomeScope GTA should know.
  • After submitting, the request appears in your dashboard under My Showings.

6. Saved Homes, Searches, and Alerts

Sign in to save homes, save searches, and manage listing alerts.

Saved Homes

Use the Save button on listing cards or listing pages to keep homes for later, compare them, and keep notes.

Saved Searches

After filtering listings, save the search and turn on alerts so new matching listings can be emailed to you.

8. School Search

Use /schools if school-area research matters to your home search.

  • Search by school name, board, program, municipality, and level.
  • Sort by rating in both directions.
  • Sort by school name in both directions.
  • Use pagination to continue beyond the first set of results.
  • Open school profile pages to review school details and nearby homes.
School boundaries and eligibility can change. Always verify school assignment, transportation, and eligibility directly with the school board before making a decision.
