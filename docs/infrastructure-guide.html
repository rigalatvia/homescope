1. System Overview

HomeScope GTA is a Next.js App Router website for GTA real estate listings, buyer and renter guides, showing request capture, operational admin tooling, Firestore-backed telemetry, and a site knowledge chatbot.

Public Features

  • Listings search and filters
  • Listing detail pages with map and guide links
  • Guides for buyers, renters, and document prep
  • Contact form and showing request flow
  • Search logging and chatbot assistance

Operational Features

  • Manual and scheduled MLS sync
  • Sync statistics, stop controls, and cleanup logic
  • Featured listings management
  • Lead and contact review in admin
  • Server-side secret loading and email integration

Important Runtime Rule

The site only publicly exposes listings that are visible, permitted to advertise, and in the supported municipalities. All lead, search, contact, settings, and chat writes are server-side only.

7. MLS Sync Flow

Full Sync

Manual or batch-run process to walk source pages, normalize listings, and upsert them into Firestore.

Key files:

  • lib/mls/sync/runFullSync.ts
  • lib/mls/sync/fullSyncCursor.ts
  • app/api/admin/mls-sync/route.ts

Incremental Sync

Primary recurring job. Fetches changes since the last checkpoint and updates scheduler status.

Key files:

  • lib/mls/sync/runIncrementalSync.ts
  • lib/mls/sync/incrementalSyncCursor.ts
  • app/api/internal/mls-sync/scheduled/route.ts

8. Sync Cleanup Logic

Special municipality cleanup exists to remove listings incorrectly imported under King.

  • Kingston is removed if misclassified
  • Kingsville is removed if misclassified
  • Cleanup runs during both full and incremental sync

10. Deployment Plan for a New Environment

  1. Create a new Firebase / GCP project.
  2. Enable Firestore.
  3. Create or assign a service account with Firestore and Secret Manager access.
  4. Deploy Firestore rules and indexes.
  5. Set all required environment variables and secrets.
  6. Create settings/site in Firestore.
  7. Deploy the Next.js app.
  8. Configure the scheduler to call /api/internal/mls-sync/scheduled.
  9. Run the first sync from /admin/sync.
  10. Verify forms, listings, guides, search logging, and chatbot behavior.

11. Migration Checklist

Before Go-Live

  • Set production domain and NEXT_PUBLIC_SITE_URL
  • Verify Firebase Admin credentials
  • Verify DDF secrets
  • Verify email provider and sender
  • Verify admin and scheduler tokens

After Go-Live

  • Run first sync and confirm listings count
  • Test showing request and thank-you redirect
  • Test contact form and email delivery
  • Test search logging and chatbot persistence
  • Verify sitemap and robots output

12. Recommended Improvements

  • Add explicit Firestore rules entries for contacts, searches, and chatConversations.
  • Add automated backups and recovery procedures for Firestore.
  • Add monitoring and alerting around sync failures and email delivery.
  • Add smoke tests for lead, contact, and sync routes.
  • Consider an AI-backed chatbot if broader question answering is needed.
